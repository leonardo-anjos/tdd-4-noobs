# tdd-4-noobs

welcome! this project aims to help you learn and apply test-driven development (tdd) principles while working with node.js

## types of tests covered

in this repository, we cover the following types of tests:

1. **unit tests**: 
   - focus on testing individual units of code (usually functions or methods) in isolation
   - ensure that small, discrete pieces of functionality work as expected

2. **integration tests**: 
   - test the interaction between different modules or components of the application
   - verify that multiple parts of the system work together as intended

3. **api tests**:
   - test the external interfaces of the application (e.g., rest apis)
   - ensure that api endpoints return the correct responses and handle different scenarios properly

4. **end-to-end (e2e) tests**:
   - test the entire application flow from the user's perspective
   - ensure that all the integrated components work together seamlessly from start to finish

## getting started

1. clone this repository: 
   ```bash
   git clone https://github.com/leonardo-anjos/tdd-4-noobs
   ```

2. install dependencies:
   ```bash
   npm install
   ```

3. run the tests:
   ```bash
   npm test
   ```

## contributing

we welcome contributions to improve the repository and help others learn tdd with node.js!

to contribute:

1. fork the repository
2. create a new branch (`git checkout -b feature-name`)
3. make your changes and add tests for any new functionality
4. run the tests to ensure everything works
5. submit a pull request with a description of your changes
